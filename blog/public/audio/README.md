# Audio reference

Short sound-effect excerpts from the user-supplied [PS2 Menu walkthrough](https://www.youtube.com/watch?v=HUyRfqJew1A), uploaded by chaoreturnsforgood76. Original console audio: Sony Computer Entertainment.

Source ranges (seconds): startup 2.08–8.58, cursor 13.30–13.72, enter 16.92–17.72, back 72.25–72.90, ambience 78.10–81.10. UI clips have short fades and a 90 Hz high-pass filter; the ambience is crossfaded into a seamless 2.65-second loop. MP3, mono, 44.1 kHz, 96 kbps. No video frames, logos, or spoken content are bundled.
